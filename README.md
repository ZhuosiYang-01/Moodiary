# [在线体验：心屿 Moodiary](https://zhuosiyang-01.github.io/Moodiary/)

一个简约舒缓的情绪日记与自我关怀网页。支持情绪记录、触发因素、浏览器本地保存、自我关怀建议，以及包含 78 张牌的塔罗情绪觉察功能。

## 隐私说明

日记内容只保存在当前浏览器的本地存储中，不会上传到服务器。

## 使用说明

访问上方网站链接即可使用，也可以下载仓库后直接打开 `index.html`。

## 数据来源

塔罗牌基础资料来源于 [look-fate/tarot-lab](https://github.com/look-fate/tarot-lab)。塔罗功能仅用于情绪觉察和自我反思，不提供心理诊断或未来预测。
